# Brewocrat — Brewery · Skybar · Kitchen

A polished landing page for Brewocrat, the rooftop microbrewery at Element One, Sector 47, Gurugram.

- Vite + React + TypeScript + Tailwind CSS
- Framer Motion and Lenis for animation and smooth scrolling
- An opening "pour" preloader: a brass tap fills a pint with a wavy amber surface, rising carbonation and a foam head that settles before the brand reveal. You can skip it by clicking or pressing any key, and it respects `prefers-reduced-motion`.
- Sections: hero video, about, four taps (interactive), signature plates, moments, Tap Dossier and social formats, weekly live programming, the three spaces, gallery with lightbox, reservation and visit info with map, patron reviews, footer
- `/menu`: the full food menu (162 items) and drinks menu (152 items), with category filters and search

All copy, prices and images come from the original site (https://brewocrat2-iota.vercel.app). Images were converted to WebP, and the hero video was re-encoded for the web.

```bash
npm install
npm run dev
npm run build
```
